# ADR-0001：使用原生单进程菜单栏架构

## 状态

已接受

## 背景

应用只在一台 Mac 上监控当前用户进程，数据量小，刷新周期约 2 秒。首版不需要远程服务、持久化或管理员权限。

## 决策

使用 Swift 6、SwiftUI `MenuBarExtra` 和单个 macOS 应用进程，最低支持 macOS 14。采集、归并、状态和界面通过清晰的本地协议边界分层。

## 影响

优点：依赖少、安装简单、系统集成自然，适合当前规模。  
缺点：较复杂的菜单栏窗口交互可能需要少量 AppKit 补充；不兼容 macOS 13 之前版本。

## 备选方案

- Electron：Web UI 开发方便，但资源占用和分发体积不符合轻量菜单栏工具定位。
- 独立 daemon 加 UI 客户端：隔离性更强，但首版没有需要常驻后台服务解决的问题，运维复杂度过高。
