# ADR-0002：首版使用 lsof 与 libproc 采集

## 状态

已接受

## 背景

应用需要建立监听端口、进程、工作目录和内存之间的关联。完全自行遍历 Darwin socket 内核结构会显著增加首版实现和兼容成本。

## 决策

端口使用系统自带 `/usr/sbin/lsof` 的字段输出采集；进程路径、工作目录、启动信息和内存使用 Darwin `libproc` API。二者通过可替换协议接入发现引擎。

## 影响

优点：实现直接，复用系统工具，字段解析可以用固定样例充分测试。  
缺点：创建子进程有性能成本，系统工具输出仍需防御性解析。若单轮采集无法达到 500 ms 目标，需要替换端口采集器。

## 备选方案

- 解析 `netstat` 表格输出：难以稳定映射 PID，拒绝采用。
- 首版直接实现原生 socket 枚举：运行时性能更好，但实现复杂度与当前需求不成比例。
