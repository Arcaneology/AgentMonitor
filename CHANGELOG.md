# Changelog

## 1.0.0 - 2026-09-15

### Features

- Monitor power modes, AI token usage, device temperature, local services, ports, processes, and user LaunchAgents from one macOS menu-bar panel.
- Aggregate local Claude, Codex, Grok, and Gemini session usage with time ranges, model filters, duplicate handling, and reviewable uncertain records.
- Switch between Normal, Sleep, and Server power modes and schedule Sleep or Server rules for every day or weekdays.
- Discover local development projects and open detected HTTP ports directly in the browser.
- Stop user-owned services with identity checks, graceful termination, and confirmed force-stop fallback.
- Offer Chinese and English interfaces, collapsible modules, live menu-bar status, temperature alerts, and an About screen.

### Documentation

- Replace the engineering-oriented README with a public user guide covering installation, usage, privacy, safety, and source builds.
- Move internal design, diagnostics, acceptance evidence, and release notes out of the public repository surface.
